Resumo

Operadores são os símbolos que fazem operações com valores. Há os que calculam (aritméticos), os que comparam e devolvem boolean (relacionais), os que combinam condições (lógicos) e os que guardam valores em variáveis (atribuição). O curso cria a classe Aula04Operadores e faz tudo nela.

15 · Aritméticos: + - * /

  • Com int numero1 = 10 e int numero2 = 20: numero2 - numero1 dá 10, + dá 30 e * dá 200. O resultado pode ir direto no println ou ser guardado numa variável (int resultado = numero1 + numero2;).
  • O + é sobrecarregado: soma números, mas vira concatenação a partir do momento em que aparece uma String, lendo da esquerda para a direita:
    • "Valor " + numero1 + numero2 → "Valor 1020"
    • numero1 + numero2 + " valor" → "30 valor", porque primeiro soma e depois encontra a String
    O William avisa que esse tipo de conta é mais comum em prova de certificação do que no dia a dia.
  • Divisão entre inteiros dá inteiro: 10 / 20 dá 0, e não 0.5. A parte decimal é descartada.
  • Para ter 0.5, basta que um dos lados seja decimal: double numero2 = 20.0, ou um cast como (double) numero1 / numero2. O cast funciona, mas a aula chama de "feio": é bom saber que existe.

16 · Resto e relacionais

  • Resto (%): 20 % 2 dá 0. Se o resto da divisão por 2 é 0, o número é par, e se não é, é ímpar.
  • Relacionais comparam valores e sempre devolvem boolean (true/false): <, >, <=, >=, == e !=.
  • = atribui e == compara. Com um sinal só, a comparação não compila.
  • O nome da variável pode deixar claro o que ela guarda: boolean isDezMaiorQueVinte = 10 > 20; (false). Na hora de imprimir, vale pôr um rótulo: "isDezMaiorQueVinte " + isDezMaiorQueVinte.
  • 10 == 10.0 é true: int e double são tipos comparáveis, e o int é promovido para double.
  • Comparar tipos incomparáveis, como 10 == "10", é erro de compilação.
  • String tem um caso especial: evite == para comparar Strings. O motivo fica para a parte de String.
  • No IntelliJ, uma variável declarada e nunca usada fica cinza ("is never used"). Dá para apagar sem medo.

17 · Lógico AND: &&

  • Os três lógicos: && (E), || (OU) e ! (NÃO). Eles fazem mais sentido com if, então aqui é só a introdução.
  • Com &&, todas as condições precisam ser verdadeiras para o resultado ser true.
  • O exemplo da aula é o visto de imigrante qualificado na Holanda: com 30 anos ou mais, o salário mínimo exigido é €4.612; com menos de 30, é €3.381.
int idade = 35;
float salario = 3500F;
boolean isDentroDaLeiMaiorQueTrinta = idade >= 30 && salario >= 4612;
boolean isDentroDaLeiMenorQueTrinta = idade < 30 && salario >= 3381;
// idade 35 → false e false · idade 29 → false e true
  • Não dá para separar condições com vírgula. Em programação, o "e" tem que ser escrito com &&.
  • A aula usa o debug para conferir cada parte: breakpoint, Shift+F9, F8. A tabela verdade vem nas aulas de condicionais.

18 · Lógico OR: ||

  • Com ||, basta uma condição verdadeira para o resultado ser true.
  • O exemplo é comprar um PlayStation 5 se qualquer uma das duas contas tiver saldo:
double valorTotalContaCorrente = 200;
double valorTotalContaPoupanca = 10000;
float valorPlayStation = 5000F;
boolean isPlayStationCincoCompravel =
        valorTotalContaCorrente > valorPlayStation || valorTotalContaPoupanca > valorPlayStation;
// false || true → true
  • Não traduza a fala ao pé da letra. "Se a corrente ou a poupança for maior que o valor" não vira contaCorrente || contaPoupanca > valor, que nem compila. Cada lado do || é uma comparação completa.
  • IntelliJ: Ctrl+Alt+L reformata o código. No debug, Alt+F8 (Evaluate Expression) calcula qualquer expressão selecionada antes de a linha executar.
  • A negação (!) fica para depois do if.

19 · Atribuição, incremento e decremento

  • Além do =, existem +=, -=, *=, /= e %=. Eles só economizam código: bonus += 1000 é o mesmo que bonus = bonus + 1000.
  • Com double bonus = 1800: += 1000 dá 2800, -= 1000 volta a 1800, *= 2 dá 3600, /= 2 volta a 1800 e %= 2 dá 0.
  • Evite hard code: escrever bonus = 2800 "funciona", mas quebra quando o bônus inicial mudar. Use o valor da variável: bonus = bonus + 1000.
  • Não dá para declarar a mesma variável duas vezes (double bonus duas vezes). Para mudar o valor, só atribua de novo.
  • Incremento e decremento: contador++ soma 1 e contador-- subtrai 1. São atalhos para contador += 1. Precisa ser o sinal duplo: +++ ou + sozinho não servem.
  • Pós × pré:
    • contador2++ (pós): primeiro usa o valor e depois incrementa. println(contador2++) imprime 0, e a variável passa a valer 1.
    • ++contador2 (pré): primeiro incrementa e depois usa. println(++contador2) imprime 1.
    Isso vai aparecer muito nos laços de repetição.

Atenção

  • double r = 10 / 20; dá 0.0. A divisão entre dois ints acontece antes e só o resultado (0) é convertido. Guardar num double não salva a conta.
  • (double) (10 / 20) também dá 0.0, porque o cast vem tarde demais. O certo é (double) 10 / 20, que dá 0.5.
  • if (x = 5) não compila em Java, porque x = 5 é um int e não um boolean. É uma proteção que o PHP não tem.
  • Extra: curto-circuito. && não avalia o lado direito se o esquerdo já é false. || não avalia se o esquerdo já é true. Por isso b != 0 && a / b > 1 é seguro. (& e | simples avaliam os dois lados.)
  • Extra: divisão por zero. Entre ints dá erro na execução (ArithmeticException). Com double dá Infinity ou NaN, sem erro.
  • Extra: % com negativos. -7 % 2 dá -1. Para testar ímpar, use n % 2 != 0, e não == 1.
  • Extra: += faz cast escondido. byte b = 10; b += 5; compila, mas b = b + 5; não (a soma vira int).
  • Precedência: * / % vêm antes de + -. Na dúvida, use parênteses.

Paralelo com PHP

  • Divisão: no PHP, 10 / 20 dá 0.5. No Java dá 0. O equivalente em PHP à divisão inteira do Java é intdiv(10, 20). É a pegadinha mais perigosa desta página.
  • Igualdade: Java não tem ===. Entre primitivos, o == já é "estrito" quanto ao tipo: 10 == "10" é true no PHP e erro de compilação no Java. A exceção é a promoção numérica, que faz 10 == 10.0 dar true.
  • Concatenar: .= no PHP é += no Java (texto += " mais").
  • Lógicos: &&, || e ! são iguais e também fazem curto-circuito. As palavras and/or do PHP não existem em Java.
  • Iguais nas duas: ++/-- pré e pós, os compostos += -= *= /= %= e a precedência.

Glossário

  • Operador aritmético: faz conta (+ - * / %).
  • Operador sobrecarregado: um mesmo símbolo com mais de um comportamento, como o + (soma ou concatena).
  • Resto (módulo): %, o que sobra da divisão inteira.
  • Operador relacional: compara e devolve boolean (< > <= >= == !=).
  • Operador lógico: combina booleans (&& || !).
  • Curto-circuito: parar de avaliar quando o resultado já está definido.
  • Operador de atribuição composto: += -= *= /= %=.
  • Operador unário: atua sobre uma variável só (++, --, !).
  • Hard code: valor fixo escrito no código onde deveria vir de uma variável ou cálculo.
  • Evaluate Expression: Alt+F8 no debug, calcula uma expressão na hora.
