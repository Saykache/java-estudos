Resumo

Tudo o que foi visto de JDBC vira uma aplicação de verdade, com dados entrando pelo console: um CRUD (Create, Read, Update, Delete) de produtores e depois de animes. Cada operação segue o mesmo desenho: serviço (conversa com o usuário via Scanner), repositório (PreparedStatement criado num método auxiliar) e domínio imutável (@Value @Builder). No caminho aparecem recursos novos do Java: o switch com setas, os text blocks (""") e o Optional no findById.

Producer(id, name)  ·  Anime(id, name, episodes, producer)   // @Value @Builder

275 · CRUD pt 01: findByName e findAll

Um pacote novo, ZZJcrud, com a ConnectionFactory copiada (só o getConnection, "o mais limpo possível") e o domínio:

@Value @Builder
public class Producer {
    Integer id;
    String name;
}

@Builder @Value
public class Anime {
    Integer id;
    String name;
    int episodes;
    Producer producer;      // um anime tem um produtor (relacionamento unidirecional)
}
// ProducerRepository: o findByName com PreparedStatement das aulas 268–269
public static List<Producer> findByName(String name) {
    log.info("Finding Producer by name '{}'", name);
    List<Producer> producers = new ArrayList<>();
    try (Connection conn = ConnectionFactory.getConnection();
         PreparedStatement ps = createPrepareStatementFindByName(conn, name);
         ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            producers.add(Producer.builder().id(rs.getInt("id")).name(rs.getString("name")).build());
        }
    } catch (SQLException e) {
        log.error("Error while trying to find all producers", e);
    }
    return producers;
}

// ProducerService: conversa com o usuário
public class ProducerService {
    private static final Scanner SCANNER = new Scanner(System.in);

    public static void menu(int op) {
        switch (op) {
            case 1 -> findByName();
            case 2 -> delete();
            case 3 -> save();
            case 4 -> update();
            default -> throw new IllegalArgumentException("Not a valid option");
        }
    }

    private static void findByName() {
        System.out.println("Type the name or empty to all");
        String name = SCANNER.nextLine();                         // vazio → LIKE '%%' → todos
        ProducerRepository.findByName(name)
                .forEach(p -> System.out.printf("[%d] - %s%n", p.getId(), p.getName()));
    }
}

// CrudTest01: o laço do menu
while (true) {
    producerMenu();                                               // "1. Search for producer ... 0. Exit"
    op = Integer.parseInt(SCANNER.nextLine());
    if (op == 0) break;
    ProducerService.menu(op);
}
  • findAll = findByName com texto vazio: o menu pergunta "o nome ou vazio para todos".
  • Mensagens para o usuário vão com System.out, e o log fica para informações técnicas. Com log.info, o menu sairia cheio de data, thread e pacote.
  • Por que Integer.parseInt(scanner.nextLine()) em vez de nextInt(): o nextInt() lê o número mas deixa o Enter no buffer, e o próximo nextLine() volta vazio "e geralmente dá capim na palheta". Lendo sempre a linha inteira e convertendo, isso não acontece (aula 70).
  • No começo a lista era impressa com o índice ([0] - Madhouse). Na aula 277 passou a mostrar o id do banco, que é o que o usuário precisa digitar para deletar ou atualizar.

276 · CRUD pt 02: delete

private static void delete() {
    System.out.println("Type the id of the producer you want to delete");
    int id = Integer.parseInt(SCANNER.nextLine());
    System.out.println("Are you sure? Y/N");
    String choice = SCANNER.nextLine();
    if ("y".equalsIgnoreCase(choice)) {                 // literal primeiro: sem NullPointerException
        ProducerRepository.delete(id);
    }
}

// ProducerRepository
public static void delete(int id) {
    try (Connection conn = ConnectionFactory.getConnection();
         PreparedStatement ps = createPrepareStatementDelete(conn, id)) {
        ps.execute();
        log.info("Deleted producer '{}' from the database", id);
    } catch (SQLException e) {
        log.error("Error while trying to delete producer '{}'", id, e);
    }
}
private static PreparedStatement createPrepareStatementDelete(Connection conn, Integer id) throws SQLException {
    PreparedStatement ps = conn.prepareStatement("DELETE FROM `anime_store`.`producer` WHERE (`id` = ?);");
    ps.setInt(1, id);
    return ps;
}
  • Apagar pelo id, e não pelo nome, é o mais seguro. Por isso a lista mostra o id.
  • Confirmação ("Tem certeza?") antes de apagar. "y".equalsIgnoreCase(choice) aceita y ou Y. O professor mostra também startsWith e toUpperCase, e na gravação primeiro usou "S/N" e depois trocou para "Y/N", já que tudo está em inglês.
  • Refatorações: o Scanner virou constante (private static final Scanner SCANNER, renomeado com Shift+F6) e o buildMenu virou menu.
  • A ideia de fluxo: normalmente o usuário primeiro pesquisa e depois decide o que apagar. Dava para juntar os dois passos num método só, mas o professor mantém simples.

277 · CRUD pt 03: save e o switch novo

private static void save() {
    System.out.println("Type the name of the producer");
    String name = SCANNER.nextLine();
    Producer producer = Producer.builder().name(name).build();   // sem id: o banco gera
    ProducerRepository.save(producer);
}

private static PreparedStatement createPrepareStatementSave(Connection conn, Producer producer) throws SQLException {
    PreparedStatement ps = conn.prepareStatement("INSERT INTO `anime_store`.`producer` (`name`) VALUES (?);");
    ps.setString(1, producer.getName());
    return ps;
}
  • O repositório recebe o objeto Producer, e não só o nome: se a tabela ganhar colunas, a assinatura não muda.
  • Switch com setas (enhanced switch, que o IntelliJ oferece com Alt+Enter): case 1 -> findByName(); dispensa o break, sem risco de "cair" no próximo case. O professor data como Java 12, melhorado na 13; é definitivo desde o Java 14, e o curso usa o 15.
  • Ele também serve como expressão que devolve valor:
int i = switch (op) {
    case 1, 2, 3, 4, 5 -> 100;          // vários valores num case
    default -> throw new IllegalArgumentException();   // como expressão, precisa cobrir todos os casos
};
  • A lista virou ProducerRepository.findByName(name).forEach(p -> System.out.printf("[%d] - %s%n", p.getId(), p.getName())), sem o for com índice.
  • Ctrl+Alt+O remove os imports não usados.

278 · CRUD pt 04: update com findById e Optional

// ProducerRepository
public static Optional<Producer> findById(Integer id) {
    try (Connection conn = ConnectionFactory.getConnection();
         PreparedStatement ps = createPrepareStatementFindById(conn, id);   // WHERE id = ?
         ResultSet rs = ps.executeQuery()) {
        if (!rs.next()) return Optional.empty();                             // não achou
        return Optional.of(Producer.builder().id(rs.getInt("id")).name(rs.getString("name")).build());
    } catch (SQLException e) {
        log.error("Error while trying to find all producers", e);
    }
    return Optional.empty();
}

// ProducerService
private static void update() {
    System.out.println("Type the id of the object you want to update");
    Optional<Producer> producerOptional = ProducerRepository.findById(Integer.parseInt(SCANNER.nextLine()));
    if (producerOptional.isEmpty()) {
        System.out.println("Producer not found");
        return;
    }
    Producer producerFromDb = producerOptional.get();
    System.out.println("Producer found " + producerFromDb);
    System.out.println("Type the new name or enter to keep the same");
    String name = SCANNER.nextLine();
    name = name.isEmpty() ? producerFromDb.getName() : name;     // enter = mantém

    Producer producerToUpdate = Producer.builder()               // imutável: um objeto novo
            .id(producerFromDb.getId())
            .name(name)
            .build();
    ProducerRepository.update(producerToUpdate);                 // UPDATE ... SET name = ? WHERE id = ?
}
  • O update é "mais complicadinho": primeiro você precisa trazer o objeto do banco (findById), mostrar ao usuário e só então alterar.
  • Optional como retorno (aulas 201–202): quem chama é obrigado a tratar o "não achou". O professor comenta que também seria válido lançar exceção quando o id não existe ("se você pesquisa por id, você sabe o que está procurando"), e mostra as opções isEmpty(), isPresent() e orElseThrow. Ele fica com o isEmpty() e uma mensagem amigável.
  • Enter para manter: se o usuário não digitar nada, o ternário mantém o valor antigo.
  • Imutabilidade (@Value): não há setName, então o update monta um objeto novo com o id antigo e o nome novo. O id nunca é alterado.

279 · CRUD pt 05: CRUD de Anime

O repositório de Anime nasce da cópia do de Producer, com o Replace do IntelliJ (Ctrl+R, com Match case e Words ligados para trocar Producer→Anime e producer→anime sem estragar o resto). A novidade é que o anime tem um produtor, que está em outra tabela. Em vez de buscar cada produtor separado, um INNER JOIN traz tudo numa consulta:

private static PreparedStatement createPrepareStatementFindByName(Connection conn, String name) throws SQLException {
    String sql = """
            SELECT a.id, a.name, a.episodes, a.producer_id, p.name as 'producer_name' FROM anime_store.anime a inner join
            anime_store.producer p on a.producer_id = p.id
            where a.name like ?;
            """;                                                  // text block: sem + e \n
    PreparedStatement ps = conn.prepareStatement(sql);
    ps.setString(1, String.format("%%%s%%", name));
    return ps;
}

// montando o Anime com o Producer dentro
while (rs.next()) {
    Producer producer = Producer.builder()
            .name(rs.getString("producer_name"))                  // o alias do SELECT
            .id(rs.getInt("producer_id"))
            .build();
    Anime anime = Anime.builder()
            .id(rs.getInt("id"))
            .name(rs.getString("name"))
            .episodes(rs.getInt("episodes"))
            .producer(producer)
            .build();
    animes.add(anime);
}

// save: o produtor entra só pelo id
String sql = "INSERT INTO `anime_store`.`anime` (`name`, `episodes`, `producer_id`) VALUES ( ?, ?, ?);";
ps.setString(1, anime.getName());
ps.setInt(2, anime.getEpisodes());
ps.setInt(3, anime.getProducer().getId());

// update: nome e episódios (o produtor não muda depois de criado)
String sql = "UPDATE `anime_store`.`anime` SET `name` = ?, `episodes` = ? WHERE (`id` = ?);";
  • a e p são apelidos das tabelas (anime a, producer p). As duas têm a coluna name, então o nome do produtor ganha o apelido de coluna as 'producer_name', e é por ele que o rs.getString("producer_name") o encontra. O a.producer_id já traz o id do produtor, então não precisa do p.id.
  • Text block ("""): texto em várias linhas sem + nem \n. O conteúdo começa na linha seguinte às aspas de abertura. Preview no Java 13 e definitivo no 15. O SQL fica muito mais legível.
  • No save do anime, o usuário digita nome, episódios e o id do produtor, e basta um Producer só com o id. O professor sugere que daria para listar os produtores antes.
  • O findById do anime usa o mesmo JOIN com where a.id = ?. No update, o produtor é copiado do objeto do banco.
  • Menu de dois níveis: 1. Producer / 2. Anime / 0. Exit, cada um com seu submenu (1 a 4 e 9. Go Back). O laço do main usa switch com setas e blocos { }.
  • "Tem muita coisa que a gente poderia melhorar, várias validações, mas você tem agora um CRUD 100% funcional usando JDBC, não mais dados em memória."

Atenção

  • Correção: 9. Go Back derruba o programa no menu de produtor. O ProducerService.menu ficou com default -> throw new IllegalArgumentException("Not a valid option"), e o 9 cai nele. O AnimeService.menu não tem default e por isso "volta" sem erro. Trate o 9 no CrudTest01 (ou um case 9 -> {}).
  • Correção: três Scanner(System.in) (no CrudTest01, no ProducerService e no AnimeService). No terminal interativo costuma funcionar, mas cada Scanner tem seu próprio buffer, e o primeiro pode "engolir" linhas destinadas ao outro, o que fica evidente ao passar a entrada por arquivo ou pipe. O correto é um único Scanner compartilhado (a prática faz assim).
  • Apagar um produtor que tem animes falha: a chave estrangeira impede (SQLIntegrityConstraintViolationException), e o repositório só loga o erro. O usuário merece uma mensagem clara, ou apague os animes antes. Extra: ON DELETE CASCADE na FK apagaria em cascata, com cuidado.
  • Salvar anime com id de produtor inexistente também viola a FK.
  • Integer.parseInt em entrada vazia ou texto lança NumberFormatException e derruba o menu; o professor comenta sobre isso. Em código real, valide ou trate a exceção.
  • Switch como expressão precisa cobrir todos os casos (default); com setas não há break nem "fall-through".
  • Detalhe no repositório: o save loga "Error while trying to update" em caso de falha (mensagem copiada).

Paralelo com PHP

  • Menu no console ≈ comando Artisan: $this->choice('Opção', ['Producer', 'Anime']), $this->ask('Nome'), $this->confirm('Tem certeza?') e $this->table([...], $rows) fazem num comando o que o Scanner + printf fazem aqui (e o Laravel Prompts deixa ainda mais bonito). No PHP puro, readline()/fgets(STDIN).
  • O CRUD inteiro ≈ Eloquent: Producer::where('name', 'like', "%$n%")->get(), Producer::find($id) (devolve null, o nosso Optional) / findOrFail, Producer::create([...]), $p->update([...]), Producer::destroy($id). O JOIN com apelido é o Anime::with('producer') (eager loading) com belongsTo, ou DB::table('anime as a')->join('producer as p', 'a.producer_id', '=', 'p.id')->select('a.*', 'p.name as producer_name').
  • Switch com setas ≈ match do PHP 8: $i = match($op) { 1, 2, 3 => 100, default => throw new InvalidArgumentException() };. Também é expressão, sem break, e com comparação estrita.
  • Text block ≈ heredoc/nowdoc do PHP (<<<SQL ... SQL;), com a mesma ideia de indentação.

package academy.devdojo.maratonajava.javacore.ZZJcrud.test;

import lombok.Builder;
import lombok.Value;

import java.sql.*;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;
import java.util.Scanner;

public class CrudPraticaTest01 {
    private static final Scanner SCANNER = new Scanner(System.in);          // UM Scanner só

    @Value @Builder static class Producer { Integer id; String name; }
    @Value @Builder static class Anime { Integer id; String name; int episodes; Producer producer; }

    static Connection conn() throws SQLException {
        return DriverManager.getConnection("jdbc:mysql://localhost:3306/anime_store", "root", "root");
    }

    // ---------- repositório ----------
    static final String SELECT_ANIME = """
            SELECT a.id, a.name, a.episodes, a.producer_id, p.name AS producer_name
            FROM anime_store.anime a INNER JOIN anime_store.producer p ON a.producer_id = p.id
            """;

    static Anime toAnime(ResultSet rs) throws SQLException {
        Producer producer = Producer.builder().id(rs.getInt("producer_id")).name(rs.getString("producer_name")).build();
        return Anime.builder().id(rs.getInt("id")).name(rs.getString("name"))
                .episodes(rs.getInt("episodes")).producer(producer).build();
    }

    static List<Producer> findProducers(String name) throws SQLException {
        try (Connection c = conn();
             PreparedStatement ps = c.prepareStatement("SELECT * FROM producer WHERE name LIKE ? ORDER BY id")) {
            ps.setString(1, "%" + name + "%");
            try (ResultSet rs = ps.executeQuery()) {
                List<Producer> list = new ArrayList<>();
                while (rs.next()) list.add(Producer.builder().id(rs.getInt("id")).name(rs.getString("name")).build());
                return list;
            }
        }
    }

    static List<Anime> findAnimes(String name) throws SQLException {
        try (Connection c = conn();
             PreparedStatement ps = c.prepareStatement(SELECT_ANIME + "WHERE a.name LIKE ? ORDER BY a.id")) {
            ps.setString(1, "%" + name + "%");
            try (ResultSet rs = ps.executeQuery()) {
                List<Anime> list = new ArrayList<>();
                while (rs.next()) list.add(toAnime(rs));
                return list;
            }
        }
    }

    static Optional<Anime> findAnimeById(int id) throws SQLException {
        try (Connection c = conn(); PreparedStatement ps = c.prepareStatement(SELECT_ANIME + "WHERE a.id = ?")) {
            ps.setInt(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                return rs.next() ? Optional.of(toAnime(rs)) : Optional.empty();
            }
        }
    }

    static int execute(String sql, Object... params) throws SQLException {
        try (Connection c = conn(); PreparedStatement ps = c.prepareStatement(sql)) {
            for (int i = 0; i < params.length; i++) ps.setObject(i + 1, params[i]);
            return ps.executeUpdate();
        }
    }

    // ---------- console ----------
    static String ask(String question) {
        System.out.println(question);
        return SCANNER.nextLine();
    }

    public static void main(String[] args) {
        while (true) {
            int op = Integer.parseInt(ask("Menu: 1. Producer | 2. Anime | 0. Exit"));
            if (op == 0) break;
            int sub = Integer.parseInt(ask((op == 1 ? "Producer" : "Anime")
                    + ": 1. Search | 2. Delete | 3. Save | 4. Update | 9. Go Back"));
            if (sub == 9) continue;                                     // 9 não cai em default
            try {
                if (op == 1) producerMenu(sub); else animeMenu(sub);
            } catch (SQLIntegrityConstraintViolationException e) {
                System.out.println("Operação barrada pela chave estrangeira");
            } catch (SQLException e) {
                System.out.println("Erro no banco: " + e.getMessage());
            }
        }
    }

    static void producerMenu(int op) throws SQLException {
        switch (op) {
            case 1 -> findProducers(ask("Type the name or empty to all"))
                    .forEach(p -> System.out.printf("[%d] - %s%n", p.getId(), p.getName()));
            case 2 -> {
                int id = Integer.parseInt(ask("Type the id of the producer"));
                if ("y".equalsIgnoreCase(ask("Are you sure? Y/N"))) System.out.println("Deleted rows: " + execute("DELETE FROM producer WHERE id = ?", id));
            }
            case 3 -> System.out.println("Saved rows: " + execute("INSERT INTO producer (name) VALUES (?)", ask("Type the name of the producer")));
            default -> System.out.println("Not a valid option");
        }
    }

    static void animeMenu(int op) throws SQLException {
        switch (op) {
            case 1 -> findAnimes(ask("Type the name or empty to all"))
                    .forEach(a -> System.out.printf("[%d] - %s %d %s%n", a.getId(), a.getName(), a.getEpisodes(), a.getProducer().getName()));
            case 2 -> {
                int id = Integer.parseInt(ask("Type the id of the anime"));
                if ("y".equalsIgnoreCase(ask("Are you sure? Y/N"))) System.out.println("Deleted rows: " + execute("DELETE FROM anime WHERE id = ?", id));
            }
            case 3 -> {
                String name = ask("Type the name of the anime");
                int episodes = Integer.parseInt(ask("Type the number of episodes"));
                int producerId = Integer.parseInt(ask("Type the id of the producer"));
                System.out.println("Saved rows: " + execute("INSERT INTO anime (name, episodes, producer_id) VALUES (?, ?, ?)", name, episodes, producerId));
            }
            case 4 -> {
                Optional<Anime> fromDb = findAnimeById(Integer.parseInt(ask("Type the id of the anime")));
                if (fromDb.isEmpty()) { System.out.println("Anime not found"); return; }
                Anime anime = fromDb.get();
                System.out.println("Anime found " + anime.getName() + " (" + anime.getEpisodes() + ")");
                String name = ask("Type the new name or enter to keep the same");
                name = name.isEmpty() ? anime.getName() : name;
                int episodes = Integer.parseInt(ask("Type the new number of episodes"));
                System.out.println("Updated rows: " + execute("UPDATE anime SET name = ?, episodes = ? WHERE id = ?", name, episodes, anime.getId()));
            }
            default -> System.out.println("Not a valid option");
        }
    }
}

Glossário

  • CRUD: Create, Read, Update, Delete.
  • Enhanced switch: switch com ->, sem break, com vários valores por case e uso como expressão.
  • Switch expression: switch que devolve valor; precisa cobrir todos os casos.
  • Text block: String multilinha delimitada por """ (Java 15).
  • INNER JOIN: combina linhas de duas tabelas que satisfazem a condição (ON a.producer_id = p.id).
  • Alias: apelido de tabela (anime a) ou de coluna (p.name AS producer_name).
  • findById com Optional: busca por chave que devolve "valor ou vazio".
  • Confirmação: perguntar antes de uma operação destrutiva.
  • Replace com Match case/Words: substituição do IntelliJ que respeita maiúsculas e palavras inteiras.
