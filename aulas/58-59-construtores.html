Resumo

Repare nos parênteses de new Anime(). Parecem de método, mas não são: eles chamam o construtor, o código que roda quando o objeto é criado. Toda classe tem um. Se você não escrever nenhum, o compilador cria um vazio. Escrevendo o seu, você obriga quem cria o objeto a passar os dados necessários, e o init da aula 57 deixa de ser preciso. As aulas usam o pacote novo javacore.Dconstrutores, com uma cópia de Anime e dos testes.

58 · O que é um construtor

public class Anime {
    private String nome;
    private String tipo;
    private int episodios;
    private String genero;

    // acesso + NOME DA CLASSE + (parâmetros) — sem tipo de retorno, nem void
    public Anime(String nome, String tipo, int episodios, String genero) {
        this.nome = nome;
        this.tipo = tipo;
        this.episodios = episodios;
        this.genero = genero;
    }

    public Anime() {             // sobrecarga: permite criar sem dados
    }
}

// AnimeTeste01
Anime anime = new Anime("Akudama Drive", "TV", 12, "Ação");   // tudo numa linha
Anime anime2 = new Anime();                                   // tudo com valor padrão
  • A sintaxe: modificador de acesso, o nome exato da classe (por isso começa com maiúscula) e os parâmetros. Não tem tipo de retorno, nem void.
  • O construtor padrão: se a classe não declara nenhum construtor, o Java adiciona um vazio e sem parâmetros na compilação. O William abre o Anime.class na pasta out e mostra que ele está lá, mesmo sem aparecer no código. Todas as classes que você criou até agora tinham um.
  • Declarou um, perdeu o padrão. Com Anime(String nome) declarado, o compilador não adiciona mais o vazio, e new Anime() para de compilar.
  • A vantagem é forçar regras. Com o init dava para criar um anime sem nome. Com um construtor que exige o nome, isso não compila mais. Ainda dá para passar "", mas aí é uma validação para fazer dentro do construtor.
  • O construtor roda antes de qualquer método do objeto: é a primeira coisa que acontece.
  • Sobrecarga de construtores funciona como a de métodos: vários construtores com parâmetros diferentes. Com o completo e o vazio, dá para criar das duas formas.
  • Com duas classes Anime no projeto (pacotes Csobrecargametodos e Dconstrutores), atenção ao import. O Alt+Enter oferece as duas opções.

59 · Pegadinha, novos requisitos e this(...)

public class Anime {
    // ... atributos + private String estudio;

    public Anime() {
        System.out.println("Dentro do construtor sem argumentos");
    }

    public Anime(String nome, String tipo, int episodios, String genero) {
        this();                          // chama o construtor sem argumentos
        this.nome = nome;
        this.tipo = tipo;
        this.episodios = episodios;
        this.genero = genero;
    }

    public Anime(String nome, String tipo, int episodios, String genero, String estudio) {
        this(nome, tipo, episodios, genero);   // reaproveita o de 4 parâmetros
        this.estudio = estudio;
    }
}

new Anime("Akudama Drive", "TV", 12, "Ação", "Pierrot");
// 1) entra no de 5 → 2) this(...) vai para o de 4 → 3) this() vai para o vazio
//    (imprime a mensagem) → 4) volta e termina o de 4 → 5) termina o de 5 (estudio)
  • Pegadinha de certificação: public void Anime(...) é um método, não um construtor, porque tem retorno. Compila (quebrando a convenção de nome de método), mas new Anime(...) com aqueles argumentos deixa de compilar, já que o construtor "sumiu". Atenção redobrada na hora de ler o código.
  • Novo requisito, o estúdio: mudar a assinatura do construtor quebraria todo mundo que já usa, como na aula 57. A saída é um construtor a mais com 5 parâmetros.
  • Para não repetir as atribuições, um construtor chama outro com this(argumentos). Não é this.Anime(...): construtor tem essa sintaxe especial. O Java escolhe qual chamar pela quantidade e pelos tipos dos argumentos, e Ctrl+B no this(...) mostra qual é.
  • No debug (Shift+F9, F8) dá para ver a cadeia: a execução pula de construtor em construtor e depois volta, terminando cada um de baixo para cima.
  • Regra 1: this(...) só pode ser usado dentro de um construtor. Num método (imprime), não compila.
  • Regra 2: this(...) tem que ser a primeira instrução executável do construtor. Um println antes dele não compila. Um comentário antes, sim.

Atenção

  • Construtor não tem retorno. Qualquer tipo na frente, inclusive void, transforma o construtor em método.
  • O construtor padrão some quando você declara qualquer construtor. Se ainda quiser new Anime(), declare o vazio você mesmo.
  • this(...) só dentro de construtor e sempre na primeira linha. Por isso só dá para chamar um outro construtor.
  • Extra: construtor não se chama como método. anime.Anime("x") não existe. Ele só roda com new ou via this(...)/super(...).
  • Extra: ordem de criação. Primeiro os atributos recebem os valores padrão e os inicializados na declaração. Depois roda o corpo do construtor. Os blocos de inicialização (aula 60) entram nesse meio.
  • Extra: construtor e setters convivem. O construtor garante os dados obrigatórios na criação. Os setters (com validação) servem para o que pode mudar depois. Se o construtor precisar validar, chame o setter dentro dele: setEpisodios(episodios).
  • Extra: Alt+Insert → Constructor gera o construtor com os atributos que você marcar.
  • Extra: um construtor private impede new de fora da classe, útil em classes utilitárias e no padrão Singleton, mais à frente.

Paralelo com PHP

  • O nome: em PHP o construtor é __construct(). Em Java, ele tem o nome da classe. Curiosidade: o PHP 4 também usava o nome da classe como construtor, e esse estilo foi removido no PHP 8.
  • Vários construtores: o PHP tem um só __construct, sem sobrecarga. A flexibilidade vem de parâmetros opcionais, argumentos nomeados ou métodos estáticos como Anime::fromArray(). Em Java, você declara vários construtores.
  • Construtor padrão: igual nas duas, porque sem construtor declarado dá para criar o objeto sem argumentos. A diferença é que em Java, ao declarar um construtor com parâmetros, new Anime() passa a ser erro de compilação.
  • Menos repetição: a constructor property promotion do PHP 8 (public function __construct(private string $nome)) não existe em Java. O mais próximo são os record (Java 16+) ou o Alt+Insert/Lombok.
  • Encadear: this(...) chama outro construtor da mesma classe. O equivalente do parent::__construct() é o super(...), que aparece com herança.

Glossário

  • Construtor: bloco com o nome da classe, sem retorno, executado na criação do objeto com new.
  • Construtor padrão (default): construtor vazio que o compilador adiciona quando a classe não declara nenhum.
  • Sobrecarga de construtores: vários construtores com listas de parâmetros diferentes.
  • this(...): chamada a outro construtor da mesma classe. Primeira instrução, só dentro de construtor.
  • Encadeamento de construtores: um construtor delegando para outro, para não repetir código.
  • javap: ferramenta da JDK que lista os membros de um .class.
