Resumo

Até aqui o código rodava de cima para baixo, uma vez só. Estruturas de repetição (laços, loops) fazem um trecho executar várias vezes enquanto uma condição boolean for verdadeira. Java tem três laços básicos: while, do-while e for. O break e o continue controlam o laço por dentro. As classes do curso são Aula06EstruturasDeRepeticao01 a 05.

27 · while

int count = 0;
while (count < 10) {
    System.out.println(count); // 0 a 9
    count++;                   // sem isto: laço infinito
}
  • A condição, como no if, precisa ser boolean. while (count) não compila.
  • Mude o estado da variável dentro do laço, senão a condição nunca fica falsa e o programa imprime 0 0 0... "para o resto da eternidade". No IntelliJ, o quadrado vermelho (ou Ctrl+F2) para o programa.
  • O passo pode ser qualquer um: count += 5 conta de 5 em 5.
  • System.out.println(++count) incrementa antes de imprimir e mostra de 1 a 10 (lembra do pré-incremento da aula 19?).
  • Se a condição já começa falsa (count = 12), o bloco nunca executa.

27 · do-while

int count = 12;
do {
    System.out.println("Dentro do do-while"); // executa 1 vez, mesmo com 12
    count++;
} while (count < 10);
  • Igual ao while, mas a condição é testada no fim. Por isso o bloco roda pelo menos uma vez, mesmo com a condição falsa.
  • Repare no ; depois do while (...): ele é obrigatório no do-while.
  • O William conta que precisou disso uma vez em muitos anos. Existe, mas é raro.

27 · for

for (int i = 0; i < 10; i++) {
    System.out.println("For " + i); // 0 a 9
}
  • O for tem três partes separadas por ;:
    1. inicialização (int i = 0), que roda uma vez só;
    2. condição (i < 10), testada antes de cada volta;
    3. atualização (i++), que roda no fim de cada volta.
  • É o laço dos índices e contagens, por exemplo para percorrer uma lista de 50 nomes. while combina mais com "repita até achar", como "procure até encontrar um salário menor que 5 mil".
  • Os nomes i e depois j (num laço dentro de outro) são convenção. Não têm significado especial.
  • A variável pode vir de fora: for (count = 0; count < 10; count++). Mas ela precisa ter valor, porque variável local sem inicializar não compila.
  • Com uma instrução só, as chaves são opcionais em while, do-while e for. Como no if, não é recomendado.

28 · Exercício: números pares até 1.000.000

// Solução 1: de 2 em 2. Funciona... até mudarem o início para 1
for (int i = 0; i <= 1000000; i += 2) {
    System.out.println(i);
}

// Solução 2: testa cada número com %. Continua certa se o início mudar
for (int i = 0; i <= 1000000; i++) {
    if (i % 2 == 0) {
        System.out.println(i);
    }
}
  • Na solução 1, trocar o início para 1 faz o programa imprimir os ímpares, sem nenhum erro.
  • A lição: requisitos mudam. Segundo o William, uns 70% do tempo de trabalho é alterar ou acrescentar coisas em funcionalidades que já existem. Pense no que acontece se a regra mudar um pouco.
  • No IntelliJ, o atalho fori + Tab monta o for completo.

29 · break

int valorMaximo = 50;
for (int i = 0; i <= valorMaximo; i++) {
    if (i > 25) {
        break; // sai do for: imprime só de 0 a 25
    }
    System.out.println(i);
}
  • É o mesmo break do switch: encerra o laço na hora e segue para a linha depois dele.
  • Resolver só com if (i <= 25) println(i) dá a mesma saída, mas o laço continua rodando até o 50 à toa. Num sistema real, isso desperdiça processamento.
  • O break sai do laço, não do if. Fora de um laço ou switch, ele não compila (break outside switch or loop).

30 · Exercício: em quantas vezes dá para parcelar o carro?

Um carro custa 30.000 e cada parcela precisa ser de pelo menos 1.000.

double valorTotal = 30000;
for (int parcela = 1; parcela <= valorTotal; parcela++) {
    double valorParcela = valorTotal / parcela;
    if (valorParcela < 1000) {
        break; // daqui em diante as parcelas só diminuem
    }
    System.out.println("Parcela " + parcela + " R$ " + valorParcela);
}
// 1x 30000.0, 2x 15000.0 ... 30x 1000.0
  • Sem o break, o resultado aparece certo, mas o laço gira 30.000 vezes: são 29.970 voltas inúteis depois da parcela 30.
  • A primeira versão da aula usava if (…>= 1000) { imprime } else { break; }. Inverter a condição (if (< 1000) break;) economizou linhas e deixou o código mais limpo.

31 · continue

for (int parcela = (int) valorTotal; parcela >= 1; parcela--) {
    double valorParcela = valorTotal / parcela;
    if (valorParcela < 1000) {
        continue; // pula o resto DESTA volta e vai para a próxima
    }
    System.out.println("Parcela " + parcela + " R$ " + valorParcela);
}
  • break sai do laço. continue pula o resto da volta atual e volta para a próxima (no for, passa pelo parcela-- e testa a condição de novo).
  • Aqui o laço conta de trás para frente, de 30.000 até 1, com parcela--. Como valorTotal é double, é preciso um cast para iniciar a variável int: (int) valorTotal.
  • As parcelas válidas agora estão no fim, então break não serve: ele pararia logo na primeira volta. O continue pula as inválidas e imprime só da 30 até a 1.
  • Pular trabalho pesado importa: imprimir no console é caro (entrada e saída), e em sistemas reais o corpo do laço pode acessar o banco ou chamar um serviço externo.

Atenção

  • Laço infinito: esqueceu de atualizar a variável, ou a atualização vai para o lado errado (i-- com i < 10).
  • < × <=: i < 10 vai até 9 e i <= 10 vai até 10. Errar por um é o bug mais comum de laço (off-by-one).
  • Extra: ; depois do for ou do while. for (int i = 0; i < 10; i++); roda um laço vazio e o bloco de baixo executa uma vez. while (x < 10); costuma virar laço infinito.
  • Extra: escopo. O i declarado no for só existe dentro dele. System.out.println(i) depois do laço não compila.
  • Extra: laços aninhados. break e continue agem só no laço mais interno. Para sair dos dois, use um rótulo: externo: for (...) { for (...) { break externo; } }.
  • Extra: no exercício 31 a solução ainda gira 30.000 vezes, só pulando a impressão. Dava para calcular o início direto: (int) (valorTotal / 1000). Laço bom é o que nem começa as voltas inúteis.
  • Extra: for (;;) e while (true) são laços infinitos de propósito, e só param com break.

Paralelo com PHP

  • Sintaxe: while, do-while, for, break e continue são praticamente idênticos, só trocando $i por int i.
  • Escopo: no PHP, $i continua existindo depois do for (com o último valor). Em Java, o i declarado no for morre com o laço.
  • Sair de laços aninhados: o PHP usa break 2 ou continue 2. O Java usa rótulos (break externo;).
  • foreach: o foreach ($lista as $item) do PHP tem um equivalente em Java: for (String item : lista). Ele aparece na aula 35, junto com arrays.
  • Curiosidade: no PHP, continue dentro de um switch age como break. Em Java, continue dentro de um switch que está num laço vai para a próxima volta do laço.

Glossário

  • Laço / loop: estrutura que repete um trecho enquanto a condição for verdadeira.
  • Iteração: cada volta do laço.
  • Laço infinito: laço cuja condição nunca fica falsa.
  • do-while: laço que testa a condição no fim e roda pelo menos uma vez.
  • break: encerra o laço (ou o switch) imediatamente.
  • continue: pula o resto da iteração atual e vai para a próxima.
  • Off-by-one: erro por um, como usar < quando era <=.
  • Rótulo (label): nome dado a um laço para usar break/continue nele de dentro de outro laço.
