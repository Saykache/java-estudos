Resumo

"Tudo na vida é um if": atravessar a rua se não vier carro, comprar comida se tiver dinheiro. Estruturas condicionais fazem o programa escolher um caminho a partir de uma expressão boolean. O curso começa a classe Aula05EstruturasCondicionais01, criada com Alt+Insert → Java Class.

20 · if

int idade = 20;
if (idade >= 18) {
    System.out.println("Autorizado a comprar bebida alcoólica");
}
System.out.println("Fora do if"); // sempre executa
  • O que vai entre os parênteses precisa ser um boolean. O bloco só executa se ele for true. if (true) sempre entra e if (false) nunca entra.
  • Com uma instrução só, dá para omitir as chaves, mas não é recomendado, porque confunde. Muitas empresas usam formatador automático que sempre coloca as chaves.
  • Na aula, o William errou de propósito e aprendeu com isso: idade > 20 deixava de fora quem tem 18. O certo é idade >= 18 (ou > 17).
  • A condição pode ir para uma variável com nome claro: boolean isAutorizadoComprarBebida = idade >= 18; e depois if (isAutorizadoComprarBebida).
  • Negação: if (!isAutorizadoComprarBebida) se lê "se não é autorizado". É o mesmo que == false, e é a forma que você vai ver no código dos outros.
  • Pegadinhas de certificação:
    • if (idade) não compila, porque int não é boolean.
    • if (teste = false) compila quando teste é boolean. Isso é uma atribuição, não uma comparação: primeiro guarda false e depois testa o valor guardado, então nunca entra. Nunca faça isso no dia a dia.

21 · else e else if

  • else é o senão: executa quando o if dá false. Não leva condição e não existe sem um if.
  • Dois if separados são avaliados um de cada vez, sempre. if/else é uma escolha só: entra em um e pula o outro.
  • Com mais de duas saídas, use else if. O exemplo são as categorias de futebol:
int idade = 17;
String categoria;
if (idade < 15) {
    categoria = "Categoria infantil";
} else if (idade >= 15 && idade < 18) {
    categoria = "Categoria juvenil";
} else {
    categoria = "Categoria adulto"; // não precisa de "else if (idade >= 18)"
}
System.out.println(categoria);
  • Numa cadeia de else if, quando uma condição dá true, o resto é ignorado. O debug (Shift+F9, F8) mostra os saltos.
  • O último caso não precisa de condição: se não é infantil nem juvenil, só sobra adulto. Um else basta.
  • Escopo local: variáveis declaradas dentro de métodos precisam estar inicializadas antes de serem usadas. Se você tirar o else acima, o println(categoria) não compila, porque existe um caminho em que categoria nunca recebeu valor. O compilador não olha o valor da idade. Uma saída é inicializar: String categoria = "";.
  • Refatorar é mudar o código sem mudar o comportamento. Para renomear a classe use Shift+F6, que ajusta o nome do arquivo junto (os dois precisam bater).

22 · Operador ternário

  • É um atalho para o caso de um if/else simples que só serve para escolher um valor: condição ? valorSeVerdadeiro : valorSeFalso.
double salario = 6000;
String mensagemDoar = "Eu vou doar 500 para o DevDojo";
String mensagemNaoDoar = "Ainda não tenho condições, mas terei!";
String resultado = salario > 5000 ? mensagemDoar : mensagemNaoDoar;
  • Os dois valores precisam ser compatíveis com o tipo de destino. String r = cond ? "doar" : 0; dá erro, e "0" funciona.
  • Sozinho numa linha, ele dá o erro not a statement. O ternário precisa ter o resultado usado: atribuído, passado ao println ou (mais para frente) retornado de um método.
  • boolean posso = salario > 5000 ? true : false; funciona, mas é redundante. É o mesmo que boolean posso = salario > 5000;.
  • Dá para aninhar ternários para substituir um else if. O William mostra uma vez e pede para não usar: "poder é uma coisa, dever é outra".
// possível, mas difícil de ler: evite
String categoria = idade < 15 ? "infantil" : idade < 18 ? "juvenil" : "adulto";

23 · Tabela verdade

  A      B     A && B   A || B
true   true    true     true
true   false   false    true
false  true    false    true
false  false   false    false
  • && só dá true se todas forem verdadeiras. Uma falsa derruba tudo.
  • || só dá false se todas forem falsas. Uma verdadeira basta.
  • Vale para qualquer número de condições: true && true && false é false, e false || false || true é true.

23–24 · Exercício: imposto na Holanda (2020)

Dado um salário anual, calcular quanto se paga de imposto:

Salário anual            Alíquota
até 34.712               9,70%
de 34.713 a 68.507       37,35%
a partir de 68.508       49,50%
  • A resolução da aula guarda as alíquotas em variáveis (double primeiraFaixa = 9.70 / 100;) e usa uma cadeia if / else if / else. Com 70.000 o imposto dá 34.650.
  • No código, o separador decimal é o ponto: 9.70, nunca 9,70.
  • "Primeiro chegue no resultado, depois melhore o código." Existem várias soluções certas.
  • Não inicialize valorImposto com 0 "por garantia". Se um caminho esquecer de calcular, alguém que ganha 5 milhões pagaria zero. Sem inicializar, o compilador obriga todos os caminhos a atribuir um valor.
  • O else if (salarioAnual >= 34713 && salarioAnual <= 68507) poderia ser só else if (salarioAnual <= 68507), porque a cadeia já descartou os menores. O William prefere a versão explícita, que é mais fácil de ler.
  • O bug de trocar else if por if separados: com 25.000, o salário cai na 1ª faixa e também no if (salarioAnual <= 68507) seguinte, e o segundo cálculo sobrescreve o primeiro. É o tipo de bug que "leva dias para achar".
  • O próprio William errou ao vivo: guardou o cálculo em salarioAnual e imprimiu o salário em vez do imposto. A pista foi o IntelliJ deixar valorImposto cinza, sinal de variável não usada. Fique de olho nesses avisos.

Atenção

  • Extra: if (cond); com ponto e vírgula. O ; é um comando vazio e o bloco { } de baixo executa sempre. Compila sem erro.
  • Extra: sem chaves, só a primeira linha pertence ao if. Recuo não conta em Java: 
    if (idade >= 18)
    System.out.println("pode");
    System.out.println("sempre imprime!");
  • Extra: "buraco" entre faixas com double. Na resolução, <= 34712 seguido de >= 34713 deixa de fora 34712,50, que cai no else e paga 49,50%. Com valores decimais, faça as faixas encostarem: <= 34712 e depois > 34712.
  • Extra: imposto progressivo. O exercício aplica uma alíquota só sobre o salário inteiro, o que é uma simplificação. Na vida real cada faixa é tributada separadamente (veja o desafio).
  • Extra: variável declarada dentro de { } só existe ali dentro. if (x) { String msg = "oi"; } e depois println(msg) não compila. Por isso a categoria é declarada antes do if.
  • Na cadeia de else if, a ordem importa: ponha as condições mais específicas primeiro. if (idade >= 0) ... else if (idade >= 18) nunca chega ao segundo.

Paralelo com PHP

  • Só boolean: no PHP, if ($idade), if ($lista) e if ("0") funcionam pela regra de truthy/falsy. Em Java a condição tem que ser boolean: if (idade != 0).
  • elseif: o PHP aceita tudo junto. Em Java é sempre else if, com espaço.
  • Atribuição no if: if ($x = 5) é válido no PHP (e é fonte de bugs). Em Java só compila se a variável for boolean, que é a pegadinha da aula 20.
  • Escopo: no PHP, uma variável criada dentro do if continua existindo depois dele. Em Java, ela morre no }. E variável não inicializada é erro de compilação, não um null com warning.
  • Ternário: a sintaxe é igual. O PHP 8 proíbe ternário aninhado sem parênteses, e o Java permite (sem ambiguidade). Mesmo assim, evite. O ?: (elvis) e o ?? do PHP não existem em Java.
  • match / switch: no Laravel você talvez trocasse a cadeia de faixas por match(true). Em Java, o equivalente próximo é o switch, das aulas 25–26.

Ver a resolução (no estilo da aula) 
package academy.devdojo.maratonajava.introducao;

public class Aula05EstruturasCondicionais04 {
    public static void main(String[] args) {
        double salarioAnual = 70000;
        double primeiraFaixa = 9.70 / 100;
        double segundaFaixa = 37.35 / 100;
        double terceiraFaixa = 49.50 / 100;
        double valorImposto;

        if (salarioAnual <= 34712) {
            valorImposto = salarioAnual * primeiraFaixa;
        } else if (salarioAnual > 34712 && salarioAnual <= 68507) {
            valorImposto = salarioAnual * segundaFaixa;
        } else {
            valorImposto = salarioAnual * terceiraFaixa;
        }
        System.out.println(valorImposto);
        // 25000 → 2425.0 · 45000 → 16807.5 · 70000 → 34650.0
    }
}

Experimentos:

  1. Troque os else if por if soltos e rode com 25.000. Qual faixa "ganha"? Por quê?
  2. Apague o else e compile. Leia a mensagem variable valorImposto might not have been initialized.
  3. Reescreva as categorias de futebol com ternário aninhado e compare a leitura.
  4. Ponha um ; logo depois de if (salarioAnual <= 34712) e veja o que acontece.

Desafio (imposto progressivo): calcule como na vida real: 9,70% sobre os primeiros 34.712, 37,35% só sobre o que passar disso até 68.507, e 49,50% sobre o resto. Para 70.000, o resultado deve ser 3.367,06 + 12.622,43 + 739,04 = 16.728,53.

Glossário

  • Estrutura condicional: comando que escolhe o que executar a partir de um boolean.
  • Bloco: trecho entre { }, que define também o escopo das variáveis declaradas nele.
  • Cadeia else if: sequência de condições em que só o primeiro caso verdadeiro executa.
  • Operador ternário: cond ? a : b, uma expressão que devolve um de dois valores.
  • Tabela verdade: todas as combinações de true/false e o resultado de && e ||.
  • Escopo local: variáveis de método, que precisam ser inicializadas antes do uso.
  • Refatorar: melhorar a estrutura do código sem mudar o comportamento.
  • Imposto progressivo: cada faixa da renda é tributada com a sua alíquota.
