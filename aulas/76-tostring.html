Resumo

Desde a aula 39, imprimir um objeto mostra algo como ...Anime@1b6d3586. Agora dá para entender o porquê: toda classe é um Object (aula 74), e Object tem o método toString(), que o println chama sozinho. Como é um método herdado, ele pode ser sobrescrito. Com isso, o método imprime() que o curso escrevia em cada classe deixa de ser necessário.

De onde vem o Classe@hash

// o que Object.toString() faz (ver com Ctrl+B em Object, Ctrl+F "toString"):
public String toString() {
    return getClass().getName() + "@" + Integer.toHexString(hashCode());
}

Anime anime = new Anime("Dr. Stone");
System.out.println(anime);
// academy.devdojo.maratonajava.javacore.Isobrescrita.dominio.Anime@1b6d3586
  • getClass().getName() é o nome completo da classe (pacote + nome), seguido de @ e do hash code em hexadecimal.
  • Toda vez que você passa um objeto para o println, ele chama toString(). Escrever System.out.println(anime.toString()) é redundante.

Sobrescrevendo

package academy.devdojo.maratonajava.javacore.Isobrescrita.dominio;

public class Anime extends Object {        // "extends Object" é implícito; está aqui só para lembrar
    private String nome;

    public Anime(String nome) {
        this.nome = nome;
    }

    @Override
    public String toString() {              // mesma assinatura do Object
        return "Anime{" +
                "nome='" + nome + '\'' +
                '}';
    }
    // getNome / setNome
}

// AnimeTest01
Anime anime = new Anime("Dr. Stone");
System.out.println(anime);                  // Anime{nome='Dr. Stone'}
  • Basta declarar public String toString() na sua classe. O IntelliJ mostra o ícone de "overrides" na margem.
  • Pode retornar o que fizer sentido para um ser humano ler: só this.nome, ou algo mais descritivo.
  • @Override é a garantia: com a anotação, errar o nome (toStrin) vira erro de compilação. Sem ela, você só teria criado um método novo, e o println continuaria mostrando Classe@hash.
  • A IDE gera: Alt+Insert → toString(), marque os atributos e dê OK. O formato padrão é Anime{nome='Dr. Stone'}.

As regras da sobrescrita

  • Mesmo nome e mesmos parâmetros, em quantidade e tipo. Se o original não tem parâmetros, o sobrescrito também não tem.
  • Tipo de retorno igual ou uma subclasse dele. Isso se chama retorno covariante: onde a mãe retorna Pessoa, a filha pode retornar Funcionario.
  • O modificador de acesso não pode ser mais restritivo. Se o toString() de Object é public, o seu também tem que ser. protected String toString() dá erro (attempting to assign weaker access privileges). Pode manter ou dar mais acesso, nunca tirar.
  • O William promete detalhar essas regras nas próximas aulas. O resumo prático: na dúvida, coloque @Override, e o compilador confere tudo.

Atenção

  • tostring() ≠ toString(). Sem @Override, um erro de digitação cria outro método e ninguém percebe.
  • Extra: concatenação também chama toString(). "Assistindo: " + anime vira "Assistindo: Anime{nome='Dr. Stone'}".
  • Extra: referência null. println(anime) com anime == null imprime null, mas anime.toString() lança NullPointerException. Mais um motivo para não chamar toString() explicitamente.
  • Extra: relação bidirecional + toString = StackOverflowError. Se o toString() do Jogador inclui o time, e o do Time inclui os jogadores, um chama o outro sem fim (é o problema da aula 67). Num dos lados, mostre só o nome.
  • Extra: cuidado com dados sensíveis. O toString() aparece em logs e no debugger. Nunca inclua senha, token ou dado pessoal sem necessidade.
  • Extra: Arrays.toString(animes) usa o toString() de cada elemento, e passa a mostrar [Anime{nome='Dr. Stone'}, ...].

Paralelo com PHP

  • __toString() × toString(): mesma ideia. echo $anime no PHP chama __toString(), assim como System.out.println(anime) chama toString().
  • Sem implementar: no PHP, echo $objeto sem __toString dá erro (Object could not be converted to string). Em Java nunca dá erro, porque sempre existe o toString() herdado de Object, que imprime Classe@hash.
  • No Laravel: o __toString() de um Model devolve o JSON (toJson()). Em Java você decide o formato; a IDE gera o estilo Anime{nome='...'}.
  • Interface: no PHP 8, a classe com __toString implementa Stringable automaticamente. Em Java não é preciso, porque todo objeto já tem toString().
  • Depuração: var_dump/dd() mostram o objeto inteiro sem escrever nada. Em Java, um bom toString() é o que torna o println e os logs úteis.

Glossário

  • toString(): método de Object que devolve uma representação em texto do objeto.
  • Hash code: número inteiro associado ao objeto, mostrado em hexadecimal no toString() padrão.
  • @Override: anotação que pede ao compilador para confirmar que o método sobrescreve um da superclasse.
  • Retorno covariante: o método sobrescrito pode retornar uma subclasse do tipo original.
  • Anotação: metadado com @ que o compilador ou frameworks leem (@Override, e depois muitas outras).
