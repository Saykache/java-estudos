Resumo

Java é compilado e interpretado. Você escreve código em .java, o compilador javac transforma em bytecode (.class), e a JVM executa esse bytecode em qualquer sistema operacional que tenha uma JVM instalada. É daí que vem o lema "Write once, run anywhere".

Conceitos-chave

  • Código-fonte (.java): o que você escreve.
  • javac: compilador; gera bytecode, não código de máquina.
  • Bytecode (.class): código intermediário, independente de plataforma.
  • JVM: máquina virtual que carrega, verifica e executa o bytecode.
  • JIT (Just-In-Time): compila trechos muito usados em código nativo durante a execução.
  • JDK: kit do desenvolvedor, com compilador, ferramentas e JVM.
  • JRE: só o necessário para rodar (JVM + bibliotecas).

Atenção

  • O bytecode é portável; a JVM não é. Cada sistema tem a sua.
  • JVM ≠ JRE ≠ JDK: o JDK contém o JRE, que contém a JVM.
  • Desde o Java 11 a Oracle não distribui mais o JRE separado; na prática você instala o JDK.

Paralelo com PHP

O PHP também compila para um código intermediário (opcodes), que o OPcache guarda em memória, e o PHP 8 tem JIT. A diferença é que no Java a compilação é uma etapa explícita (javac) e o .class é um arquivo que você distribui.

Mapa mental

Como Java funciona
├── Escrita: Ola.java
├── Compilação: javac → Ola.class (bytecode)
├── Execução: java Ola
│   └── JVM
│       ├── Class Loader (carrega)
│       ├── Verificador de bytecode (segurança)
│       ├── Interpretador + JIT (executa)
│       └── Garbage Collector (memória)
└── Ferramentas: JDK ⊃ JRE ⊃ JVM

Glossário

  • Bytecode: instruções para a JVM, não para o processador.
  • Class Loader: parte da JVM que carrega os .class na memória.
  • Garbage Collector: libera automaticamente a memória de objetos não usados.
  • .jar: arquivo compactado que agrupa vários .class e recursos.

Prática (5 minutos)

// Ola.java
public class Ola {
    public static void main(String[] args) {
        System.out.println("Olá, Java!");
    }
}
sudo apt install openjdk-21-jdk   # no WSL/Ubuntu
javac Ola.java                    # gera Ola.class
java Ola                          # executa (sem extensão)
