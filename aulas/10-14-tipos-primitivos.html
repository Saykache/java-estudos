Resumo

Um tipo primitivo guarda na memória um valor simples, como um número, um caractere ou verdadeiro/falso. Java tem 8 primitivos, todos em letra minúscula e todos palavras reservadas. Em Java toda variável tem um tipo fixo, declarado antes do nome. Esse tipo define quanto espaço a variável ocupa e, por isso, que valores cabem nela.

10 · Variáveis e convenções

  • Para manter a ordem das aulas, o William renomeou as classes para Aula01OlaDevDojo, Aula02TiposPrimitivos e assim por diante (Shift+F6). Ele mesmo avisa que número em nome de classe é má prática: é só para organizar o curso.
  • psvm + Tab cria o main. Não tem problema usar atalhos desde o começo.
  • Sintaxe: tipo nome = valor; Por exemplo, int idade = 10;. O = guarda o valor no espaço de memória que o nome da variável representa.
  • Classes usam PascalCase (TiposPrimitivos). Variáveis usam camelCase: a primeira palavra em minúsculo e as seguintes com a inicial maiúscula (idadeDoPai, idadeDoPaiNaHoraDoCadastro).
  • Recomendação da aula: dê nomes em inglês. É o padrão do mercado e prepara você para equipes internacionais.
  • println(idade) imprime o valor da variável. println("idade") imprime o texto literal "idade".
  • Para juntar texto e variável, use o +: "A idade é " + idade + " anos". Separar com vírgula dá erro de compilação. O printf, que aceita vírgulas, fica para depois.

11 · Os 8 primitivos e o tamanho

Tipo     Tamanho   Guarda                   Faixa / exemplo
byte     1 byte    inteiro                  -128 a 127
short    2 bytes   inteiro                  -32.768 a 32.767
int      4 bytes   inteiro (o padrão)       ~ -2,1 bi a 2,1 bi
long     8 bytes   inteiro grande           ~ ±9,2 quintilhões
float    4 bytes   decimal                  2500.5F
double   8 bytes   decimal (o padrão)       2000.0
char     2 bytes   um caractere (Unicode)   'M'
boolean  —         true ou false            true
  • Menos o boolean, todos são numéricos, inclusive o char. O que muda entre eles é quanto cabe.
  • Por que o byte vai de -128 a 127? 1 byte são 8 bits. Um bit indica o sinal, então sobram 7 para o valor: 2⁷ = 128 combinações. O lado negativo tem um valor a mais porque o zero fica do lado positivo. byte b = 128; dá erro, e byte b = -128; compila.
  • boolean aceita só true ou false. Em Java não vale 0 ou 1. true e false são reservados e não podem ser nome de variável.
  • char usa aspas simples e guarda um caractere. Tem 2 bytes para caber o Unicode, incluindo caracteres asiáticos. Como é um número por baixo:
    • char c = 65; imprime A e char c = 87; imprime W (valores da tabela ASCII);
    • char c = 'A'; imprime A (escape Unicode).
  • Hoje memória é barata e raramente vale economizar com byte/short. Mesmo assim, pense na escala: em 2014 o YouTube precisou trocar o contador de visualizações de 32 para 64 bits porque "Gangnam Style" passou de 2.147.483.647. Por outro lado, long para idade é exagero.
  • No IntelliJ: Ctrl+D duplica a linha e Ctrl+Espaço completa o código.

12 · Literais e casting

  • Literal é um valor escrito direto no código. Número inteiro escrito assim é int por padrão, e número com ponto é double.
  • float f = 2000.0; não compila, porque é um double tentando entrar num float. Use o sufixo F: 2000.0F. O f minúsculo também funciona, mas a convenção é maiúsculo. O D (double) existe, mas raramente é usado.
  • L marca um literal long: 10000000000L. Prefira maiúsculo, porque l parece 1. int x = 1L; dá erro, já que é um long indo para um int.
  • A exceção: um literal inteiro que cabe vai direto para byte/short (byte b = 127;, short s = 32767;). Passou do limite, ele é tratado como int e dá erro.
  • A analogia do balde: jogar um balde de água (long) num copo (int) pode transbordar. Por isso o compilador não deixa.
  • Cast é forçar a conversão com o tipo entre parênteses:
    • (int) 10000000000L → número "estranho": os bits que sobram são cortados, sem aviso.
    • (float) 2500.0 → 2500.0: coube, então funciona.
    • (long) 155.23 → 155: a parte decimal é descartada, sem arredondar.
  • Conselho da aula: cast em geral é má prática. Na maioria das vezes é melhor trocar o tipo da variável.

13 · String

  • String não é primitivo. É uma classe, um tipo de referência, e por isso tem S maiúsculo. string minúsculo dá erro.
  • Usa aspas duplas: String nome = "William";. Aceita textos longos e acentos.
  • Concatena com +, igual aos primitivos: "Oi, meu nome é " + nome.
  • sout + Tab gera o System.out.println(), e Ctrl+Shift+F10 roda a classe aberta.
  • Language level 8: o curso usa a JDK 15, mas configura o projeto para aceitar só recursos do Java 8. O motivo é que muitas vagas usavam 8 ou 11, e misturar versões confunde. O caminho é F4 (Project Structure) → Project → Language level = 8, e o mesmo em Modules. Com isso, o var (Java 10, que deixa omitir o tipo) passa a dar erro.

14 · Exercício + debug

  • O exercício: criar variáveis para nome, endereço, salário e data de recebimento e imprimir: "Eu <nome>, morando no endereço <endereço>, confirmo que recebi o salário de <salário>, na data <data>".
  • Na resolução, salario é double. O tipo certo para dinheiro é BigDecimal, que ainda não foi visto. A data fica numa String, porque os tipos de data também vêm depois.
  • Nomes que explicam o conteúdo: dataRecebimentoSalario e não data. O nome é a documentação, na mesma linha da aula 09.
  • Dá para montar a frase numa variável (String relatorio = ...) e imprimir depois, ou montar direto no println. Com a variável, você pode reusar a frase.
  • Debug no IntelliJ:
    • clique na margem para pôr um breakpoint e rode com Shift+F9 (o ícone do inseto);
    • F8 executa linha a linha (Step Over), e o painel mostra o valor de cada variável na memória;
    • F9 continua até o fim (Resume), e o quadrado vermelho para;
    • o Run normal (Shift+F10) ignora os breakpoints.

Atenção

  • Shift+F10 roda a classe selecionada no menu de cima, que pode não ser a que está aberta. Ctrl+Shift+F10 roda a classe aberta no editor.
  • long x = 10000000000; não compila, mesmo a variável sendo long. O literal é int e não cabe num int. Precisa do L.
  • float f = 2.5; não compila: falta o F.
  • Cast não arredonda: (int) 9.99 dá 9.
  • Passar do limite num cálculo não dá erro, dá a volta: 2147483647 + 1 vira -2147483648 num int.
  • 'A' (aspas simples) é char e "A" (aspas duplas) é String. char c = "A"; dá erro, e 'AB' também.
  • Na concatenação, a leitura é da esquerda para a direita: "Total: " + 10 + 5 dá "Total: 105". Para somar antes, use parênteses: "Total: " + (10 + 5).
  • Boolean com B maiúsculo "também funciona", mas é outra coisa: uma classe wrapper, assunto de aulas futuras.
  • Sobre versões: hoje (2026) o mercado roda principalmente 17 e 21, e ainda existe muito Java 8/11 legado. Seguir o curso em nível 8 não atrapalha. Só lembre que var, switch com seta, record etc. são de versões mais novas.

Paralelo com PHP

  • Concatenação: no PHP é . e no Java é +. "1" + 2 dá 3 no PHP e "12" no Java. É a pegadinha número um de quem vem do PHP.
  • Tipos: o PHP tem só int (64 bits, igual ao long), float (que na verdade é um double), bool e string. Não existe byte, short nem char. E a variável PHP muda de tipo, enquanto a do Java nasce e morre com o mesmo tipo.
  • Estouro: no PHP um int grande demais vira float sozinho. No Java ele dá a volta para o negativo, sem avisar.
  • Cast: a sintaxe é igual! (int) 155.23 dá 155 nas duas linguagens.
  • Booleanos: no PHP if (1) e true == 1 funcionam. No Java, boolean não se mistura com número.
  • var: parece o $x = 10 do PHP, mas não é. O compilador deduz o tipo e ele fica fixo: var x = 10; x = "oi"; dá erro.
  • Nomes: camelCase em variáveis também é o que o Laravel usa. Nada muda aqui.

Glossário

  • Tipo primitivo: tipo básico que guarda o valor direto na memória. Java tem 8.
  • Tipo de referência: tipo que aponta para um objeto, como String. Os detalhes vêm na parte de OO.
  • camelCase / PascalCase: idadeDoPai (variáveis, métodos) / TiposPrimitivos (classes).
  • Literal: valor escrito direto no código (10, 2.5F, 'A', "oi").
  • Cast: conversão forçada, (tipo) valor. Pode perder informação.
  • Overflow: passar do limite do tipo, o que faz o valor "dar a volta".
  • ASCII / Unicode: tabelas que ligam números a caracteres (65 = A).
  • Language level: versão da linguagem que o compilador aceita (javac --release).
  • BigDecimal: classe para decimais exatos, a indicada para dinheiro.
  • Breakpoint: ponto onde o debug pausa a execução.
