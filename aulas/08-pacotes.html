Resumo

Normalmente pacotes aparecem só lá pela aula 15 ou 20, mas o William preferiu mostrar logo no começo para o código já nascer organizado. Um projeto pequeno e bem estruturado passa fácil de 200 classes. Os pacotes servem para agrupar as classes que têm algo em comum.

O que é um pacote

  • No fundo, um pacote é uma estrutura de diretórios. Cada parte separada por ponto vira uma pasta.
  • academy.devdojo.maratonajava.introducao vira src/academy/devdojo/maratonajava/introducao/.
  • Toda classe que você criar deve ficar dentro de um pacote.

Convenção de nome

  • Domínio do site invertido + nome do projeto + divisão.
  • No curso: domínio devdojo.academy → academy.devdojo. Depois o projeto, maratonajava, e a divisão, introducao.
  • O projeto podia ser outro, como um crm. As divisões mudam conforme o tema. No fim do curso vão ser mais de 30 pacotes.
  • Tudo em minúsculas, sem traços e sem acentos.

A declaração package

  • Ao mover a classe OlaDevDojo para o pacote, o IntelliJ adiciona sozinho a linha:
    package academy.devdojo.maratonajava.introducao;
  • O package tem que ser a primeira linha de código do arquivo. Comentários antes dele são permitidos (comentários são o tema da próxima aula).
  • Classes criadas direto dentro do pacote já nascem com essa linha. A IDE cuida disso.
  • O nome completo da classe passa a ser academy.devdojo.maratonajava.introducao.OlaDevDojo. Isso vai importar quando uma classe usar outra de outro pacote.

No IntelliJ

  • Criar pacote: botão direito em src → New → Package.
  • Mover classe: arrastar para dentro do pacote e confirmar o Refactor. Não use copiar e colar, senão a classe fica duplicada.
  • Renomear (inclusive pacote): Refactor → Rename ou Shift+F6.
  • Compilar: Ctrl+F9 (Build). Executar: Shift+F10.
  • Show in Explorer mostra as pastas reais. A pasta out (onde ficam os .class) repete a mesma estrutura de pacotes do src.
  • A pasta out é temporária, gerada na compilação. Não precisa se preocupar com ela.

Atenção

  • Na aula o traço aparece como "não aconselhável", mas na verdade traço nem compila em nome de pacote. maratona-java é inválido. Use maratonajava ou, se precisar mesmo separar, maratona_java.
  • O domínio vai invertido: devdojo.academy vira academy.devdojo, e não o contrário.
  • Nada de código antes do package. Só comentários e linhas em branco.
  • O .class precisa ficar numa pasta igual ao pacote, senão a JVM não acha a classe. A IDE faz isso por você. Na mão, é o javac -d que monta as pastas.
  • Fora da IDE, para executar é preciso o nome completo: java -cp out academy.devdojo.maratonajava.introducao.OlaDevDojo.

Paralelo com PHP

O pacote é o namespace do PHP, e a pasta que acompanha o pacote lembra o PSR-4 do Composer (App\Http\Controllers → app/Http/Controllers). Três diferenças:

  • No Java a pasta é parte da linguagem, não uma configuração de autoload no composer.json.
  • O separador é ponto (.), não barra invertida (\).
  • A convenção é tudo minúsculo e com o domínio invertido. No Laravel é PascalCase e começa pelo vendor (App, Illuminate).

O nome completo academy.devdojo...OlaDevDojo é o equivalente ao FQCN App\Models\User.

Prática no seu WSL (10 minutos)

Mesmo exercício da aula, mas na mão, para ver o que a IDE faz:

# 1. Criar a estrutura de pastas do pacote
mkdir -p ~/java-lab/src/academy/devdojo/maratonajava/introducao
cd ~/java-lab

# 2. A classe começa com o package
cat > src/academy/devdojo/maratonajava/introducao/OlaDevDojo.java <<'EOF'
package academy.devdojo.maratonajava.introducao;

public class OlaDevDojo {
    public static void main(String[] args) {
        System.out.println("Olá DevDojo, agora dentro de um pacote!");
    }
}
EOF

# 3. Compilar: o -d cria as pastas do pacote dentro de out/
javac -d out src/academy/devdojo/maratonajava/introducao/OlaDevDojo.java
find out -name '*.class'
# out/academy/devdojo/maratonajava/introducao/OlaDevDojo.class

# 4. Executar pelo nome completo
java -cp out academy.devdojo.maratonajava.introducao.OlaDevDojo

# 5. Ver os erros (e ler as mensagens):
java -cp out OlaDevDojo            # nome curto: classe não encontrada

Desafio: crie um segundo pacote academy.devdojo.maratonajava.teste com uma classe Teste que imprime algo. Compile as duas classes num comando só (javac -d out $(find src -name '*.java')) e execute cada uma.

Glossário

  • Pacote (package): agrupamento de classes, que no disco é uma estrutura de pastas.
  • Domínio invertido: convenção para o nome do pacote ser único no mundo (com.empresa, academy.devdojo).
  • Declaração package: primeira linha de código do arquivo, diz a qual pacote a classe pertence.
  • Nome completo (fully qualified name): pacote + nome da classe.
  • Refactor: mudança de estrutura feita pela IDE, que atualiza as referências sozinha (mover, renomear).
  • Pasta out: saída da compilação no IntelliJ, com os .class na mesma estrutura dos pacotes.
