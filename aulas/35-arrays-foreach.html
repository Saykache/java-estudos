Resumo

Até a aula 34, criar um array exigia duas etapas: new int[3] e depois preencher posição por posição. Esta aula mostra duas formas de criar o array já com os valores (o tamanho é calculado sozinho) e uma forma nova de percorrê-lo: o foreach, que dispensa o índice.

Três formas de criar um array

public class Aula07Arrays03 {
    public static void main(String[] args) {
        int[] numeros = new int[3];                  // tamanho, valores padrão (0, 0, 0)
        int[] numeros2 = {1, 2, 3, 4, 5};            // valores direto: 5 posições (índices 0 a 4)
        int[] numeros3 = new int[]{5, 4, 3, 2, 1};   // new + valores, sem informar o tamanho

        for (int num : numeros3) {                   // foreach
            System.out.println(num);
        }
    }
}
  • {1, 2, 3, 4, 5}: os valores vão entre chaves, separados por vírgula e do mesmo tipo declarado. O Java conta os elementos e cria o array com esse tamanho. Economiza as linhas de numeros[0] = ....
  • new int[]{5, 4, 3, 2, 1}: outra sintaxe que dá no mesmo. Não coloque o tamanho entre os colchetes: new int[5]{...} é erro de compilação, porque quem calcula o tamanho é o Java.
  • Use o length do array que você está percorrendo. A aula mostra um for que usa numeros2.length para imprimir numeros3[i]. Funciona só porque os dois têm 5 posições: length é apenas um número. Com tamanhos diferentes, quebraria.

O foreach (for aprimorado)

for (int num : numeros3) {
    System.out.println(num);   // 5, 4, 3, 2, 1
}

// equivale a:
for (int i = 0; i < numeros3.length; i++) {
    int num = numeros3[i];
    System.out.println(num);
}
  • A sintaxe: for (Tipo variavel : array). Leia os dois-pontos como "em": "para cada num em numeros3".
  • A cada volta, a variável recebe o próximo elemento: na primeira, numeros3[0], na segunda, numeros3[1], e assim por diante. O controle de índice, a comparação com o tamanho e o incremento acontecem "por baixo dos panos".
  • O tipo da variável tem que ser o tipo dos elementos. Num int[], é int. for (String s : numeros3) não compila.
  • Não há índice. Se você precisa saber a posição (ou acessar uma posição específica), use o for comum com i.
  • O nome da variável é livre (num, x...). Ela é local ao laço e deixa de existir quando ele acaba. Declarar outra variável com o mesmo nome depois do laço funciona. Antes do laço, no mesmo bloco, dá conflito de nomes e não compila.
  • Nas palavras do William: "vocês vão utilizar muito esse for".

Atenção

  • {1, 2, 3} sozinho só vale na declaração. Depois, para atribuir, é numeros = new int[]{1, 2, 3};. A aula 38 volta a isso com arrays multidimensionais.
  • new int[3]{1, 2, 3} não compila: ou você dá o tamanho, ou os valores.
  • Extra: o foreach não altera o array. for (int num : numeros) { num = 0; } muda só a variável temporária. Para gravar, use o for com índice: numeros[i] = 0.
  • Extra: o foreach percorre sempre do primeiro ao último. Para ir de trás para frente, pular posições ou parar num índice, volte ao for comum. O break e o continue funcionam normalmente no foreach.
  • Extra: um array null no foreach lança NullPointerException. Um array vazio ({}) simplesmente não entra no laço.

Paralelo com PHP

  • Literal: $numeros = [1, 2, 3]; vira int[] numeros = {1, 2, 3};. São chaves em vez de colchetes, e em Java é tudo do mesmo tipo e com tamanho fixo depois de criado.
  • foreach: foreach ($numeros as $num) vira for (int num : numeros). O tipo vem antes, e os dois-pontos substituem o as, com a ordem invertida (a variável primeiro).
  • Sem chave: não existe foreach ($a as $i => $v) no foreach de array do Java. Precisou do índice, use o for comum.
  • Escopo: no PHP, $num continua existindo depois do laço, com o último valor, e com &$num ainda pode causar o famoso bug de referência. Em Java, a variável morre com o laço.

Glossário

  • Inicializador de array: {v1, v2, ...}, lista de valores que define o conteúdo e o tamanho.
  • Array anônimo: new int[]{...}, criado com valores e sem precisar de variável.
  • foreach / for aprimorado: for (Tipo x : array), que percorre elemento por elemento.
  • Variável de iteração: a variável do foreach, que recebe um elemento por volta.
