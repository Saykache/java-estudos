Resumo

O switch é uma estrutura condicional para escolhas simples a partir de um único valor: o dia da semana pelo número, o sexo pela letra. Fazer isso com if / else if até o 7 deixaria o código "gigantesco e feio". O switch compara a variável com cada case e fica mais fácil de ler. O curso cria a classe Aula05EstruturasCondicionais05.

25 · A estrutura

byte dia = 5;
switch (dia) {
    case 1:
        System.out.println("Domingo");
        break;
    case 2:
        System.out.println("Segunda");
        break;
    // ... 3 a 6
    case 7:
        System.out.println("Sábado");
        break;
    default:
        System.out.println("Opção inválida");
        break;
}
  • switch é palavra reservada. Entre os parênteses vai o valor a comparar, e cada case valor: diz o que fazer quando ele bate.
  • Tipos que a aula cita: char, byte, short, int e String. Um long, float, double ou boolean dá erro de compilação.
  • O break é essencial. Sem ele, depois de achar o case certo o Java continua executando os de baixo, sem testar mais nada. Com dia = 5 e sem breaks, sai Quinta, Sexta, Sábado. O nome disso é fall-through.
  • Com o break, a execução sai do bloco do switch na hora. No debug (Shift+F9, F8) dá para ver o pulo direto para o case 5 e depois para fora do bloco.
  • default é a opção padrão: roda quando nenhum case bateu. Sem ele, dia = 10 simplesmente não imprime nada.
  • O default pode ficar em qualquer posição, mas o costume é deixá-lo por último. Se ele ficar no topo e sem break, cai no case seguinte: com dia = 10, a aula mostra "Opção inválida" e "Domingo".
  • O valor do case precisa ser do mesmo tipo do switch:
    • char sexo = 'M' → case 'M': (aspas simples)
    • String sexo = "M" → case "M": (aspas duplas)
  • Depois dos dois pontos você pode abrir um bloco (case 'M': { ... }). É válido, mas raro, e o William diz que quase nunca viu.
  • O William comenta que o switch mudou do Java 12 em diante, mas o curso fica no Java 8, que é o que "a maioria das empresas usa". Hoje isso mudou: veja "O switch moderno" abaixo.

26 · Exercício: dia útil ou fim de semana

Dado um número de 1 a 7 (1 = domingo), imprimir se é dia útil ou final de semana. A solução da aula usa o fall-through a seu favor, empilhando os case:

byte dia = 7;
switch (dia) {
    case 1:
    case 7:
        System.out.println("Final de semana");
        break;
    case 2:
    case 3:
    case 4:
    case 5:
    case 6:
        System.out.println("Dia útil");
        break;
    default:
        System.out.println("Opção inválida");
        break;
}
  • O case 1 não tem nada nem break, então "cai" no case 7 e os dois imprimem "Final de semana".
  • O default não era pedido, mas o William coloca por boa prática.
  • A lição: cada desenvolvedor resolve de um jeito. Dava para fazer com if, com 7 case separados ou assim. Se é "bonito" ou não depende da equipe. Mais para frente, orientação a objetos e padrões de projeto dão mais opções.

O switch moderno (Java 14+)

Não está no vídeo, mas é o que você vai encontrar em código Java 17/21. Tem várias vantagens: setas no lugar de :, vários valores num case, nenhum fall-through (não precisa de break) e o switch pode devolver um valor.

// switch com setas (sem break, sem fall-through)
switch (dia) {
    case 1, 7 -> System.out.println("Final de semana");
    case 2, 3, 4, 5, 6 -> System.out.println("Dia útil");
    default -> System.out.println("Opção inválida");
}

// switch como expressão: devolve um valor
String tipo = switch (dia) {
    case 1, 7 -> "Final de semana";
    case 2, 3, 4, 5, 6 -> "Dia útil";
    default -> "Opção inválida"; // obrigatório: a expressão precisa cobrir todos os casos
};
  • Com o language level em 8, como no curso, isso não compila. Para testar no terminal, use javac --release 17 (ou nada, se sua JDK for 17+).
  • No Java 21 o switch também aceita pattern matching (case Integer i when i > 10 ->). Isso fica para quando chegarmos em OO.

Atenção

  • Esquecer o break é o erro clássico: compila sem aviso e executa os cases de baixo.
  • switch clássico não aceita long, float, double nem boolean. Para faixas (salario > 5000), use if. O case compara só igualdade, e case > 5: não existe.
  • Extra: o valor do case tem que ser uma constante conhecida na compilação (literal ou final). case x: com uma variável comum não compila, e dois case com o mesmo valor também não.
  • Extra: switch em String diferencia maiúsculas: "m" não bate com case "M". E se a String for null, lança NullPointerException.
  • Extra: a lista completa de tipos do switch clássico: char, byte, short, int, os wrappers deles (Character, Byte, Short, Integer), String e enum (aulas 80–83).
  • case 'M' com um switch sobre String não compila, porque o tipo do case precisa bater.

Paralelo com PHP

  • Fall-through e break: iguais nas duas linguagens.
  • Comparação: o switch do PHP compara com == (frouxo), então switch ("1") bate com case 1. Em Java os tipos têm que bater, senão não compila.
  • Tipos: no PHP qualquer valor serve, até switch (true) com condições nos cases, um truque comum para faixas. Em Java isso não existe: para faixas, use if.
  • match do PHP 8 ≈ switch com setas do Java: nos dois não há fall-through, o resultado é um valor e dá para listar vários valores (1, 7 => no PHP e case 1, 7 -> no Java). A diferença está no caso não previsto: o match lança UnhandledMatchError na execução, e o Java exige cobrir todos os casos (default) já na compilação.

Glossário

  • switch: estrutura que escolhe um trecho a executar comparando um valor com cada case.
  • case: um valor possível e o código que roda quando ele bate.
  • break: sai do bloco do switch (e dos laços, mais à frente).
  • default: o caso padrão, quando nenhum case bateu.
  • Fall-through: continuar executando os cases seguintes por falta de break.
  • Constante de compilação: valor fixo conhecido pelo compilador (literal ou final), o único aceito no case.
  • Switch expression: switch (Java 14+) que devolve um valor, com ->.
